## Suggested post

I'm building RStarStar, an experimental language and R package that turns concise
analysis code into readable R.

The aim is to make common data-analysis tasks easier to express while letting you
keep working in R. You write a .rsspps file, compile it with transpile(), or run it
with run_file(). The results and returned functions can then be used in your own
R scripts.

The current prototype supports CSV workflows, filtering, grouped summaries, text
cleaning, PNG bar charts, functions, records, and a small class system. It is still
early: installation is from source, it is not on CRAN, and the language/API may change.

I'm developing this gradually and would love to build it with other contributors.
You don't need to write compiler code to help. Trying the examples, reporting a
confusing error, improving the guide, proposing a feature with a concrete use case,
or submitting a small fix would all be valuable.

AI-assisted fixes, patches, documentation, and feature requests are welcome.
Contributors still need to understand their changes, verify them, and take
responsibility for what they submit.

Repository and getting-started guide:
[github.com/RStarStar/RStarStar](https://github.com/RStarStar/RStarStar)

If you work with R, teach data analysis, or enjoy language tooling, I'd appreciate
your feedback or a contribution. Small contributions can help this project move
forward much faster than I can manage alone.
